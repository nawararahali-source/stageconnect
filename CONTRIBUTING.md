\# Guide de contribution



\## Branches

\- `main` : version stable, déployable

\- `develop` : intégration des fonctionnalités

\- `feature/<nom>` : une branche par fonctionnalité ou correction



\## Règles

\- Aucune modification directe sur `main`.

\- Toute modification passe par une Pull Request relue avant fusion.

\- Commits explicites : `feat:`, `fix:`, `docs:`, `ci:`, `test:`.

\- Aucun secret (.env, clés API) dans le dépôt.
